### 💡 Featured Projects

*   **[DeskLens]** 
    A high-performance desktop application built with **Rust and Tauri** that brings "Google Lens" features natively to Windows/Linux. It runs silently in the background and uses OCR and image processing for real-time text extraction and visual search, consuming under 25MB of RAM.
*   **[DataWave (PortoHack 2026)]** 
    A smart automation and predictive auditing system for Foreign Trade (Comex). Built with **Python and Pandas**, it integrates with MCP protocols to validate DUIMP (Declaração Única de Importação) catalogs, helping reduce port demurrage costs.
*   **[YouTube Comment NLP Analysis]** 
    A Python pipeline using the YouTube Data API, `nltk`, and `sklearn` to extract video comments and rank them against user queries using **TF-IDF vectorization and cosine similarity**.
*   **[C.H.A.P.E.U. - Smart Lock IoT]** 
    My Electronics degree final project. A hybrid, electronically protected unified access control system utilizing **ESP32, RFID, ESP-CAM**, and Blynk for remote mobile monitoring and management.
*   **[Port of Santos Data Analysis]** 
    An end-to-end data science project analyzing atmospheric pollutants from vessels and correlating them with naval economic performance. Utilized **Python (Pandas, RegEx) for ETL** and **R (ggplot2) / Power BI** for statistical visualization.
